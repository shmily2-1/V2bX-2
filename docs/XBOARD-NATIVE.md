# Xboard 原生界面适配

面板源码位于 `shmily2-1/Xboard`。扩展配置使用原 Xboard 节点列表及编辑弹窗。机器服务、Peer 和专用用户下载入口已停用；用户界面保持原有账号、会话、权限组与订阅。

节点端仍使用原 UniProxy 配置、用户和计量接口，HTTP/Mixed 选择 sing，MASQUE 与 VLESS/XDRIVE 选择 Xray。新增功能不要求更换既有代理节点配置。

历史机器服务同步组件不再随新版本安装。旧节点上的同步进程应停止，历史配置和数据库记录不会自动删除。

不再运行 `v2bx panel-agent`。旧同步组件如需收尾，请在停用服务后手动停止；新的 Xboard/V2bX 版本不再读取这些配置。

机器服务接口仅保留历史兼容路径，不再提供新服务管理或运行时应用。

组件不额外创建代理用户、不重复读取核心原子计数器；配置写入后由运行中的 V2bX 应用，面板根据实际应用修订确认状态。代理独立运行，可由现有进程管理器托管，不自动新增系统服务、设置 NAT 或下载外部后端。

升级前请停用旧同步任务并保留服务配置、密钥和待报状态。
